# Ôn thi bằng lái ô tô hạng B – 600 câu

Web app ôn lý thuyết và thi thử bằng lái ô tô **hạng B** (B1/B2 cũ, gồm cả số tự động), dùng bộ 600 câu hỏi sát hạch mới (áp dụng từ 01/6/2025).

**Dùng trên iPhone:** mở trang GitHub Pages của repo bằng Safari → nút Chia sẻ → **Thêm vào MH chính**.

- Học theo 6 chương, 60 câu điểm liệt, ôn lại câu đã làm sai (tự lưu tiến độ trên máy)
- Thi thử theo Thông tư 12/2025/TT-BCA: 30 câu, 20 phút, đạt 27/30, không sai câu điểm liệt
